# Screenshot notes

The images in this directory show the installed **Listi 0.38.0-23 alpha** on Haiku x86_64 in a virtual machine. The screenshots were cropped to the native window or dialog. The folders, documents and notes in the *Lunar atlas* project are example data.

The photograph in [Quick view](photo-quick-view.png) is **The Blue Marble**, taken by the **NASA / Apollo 17 crew** on December 7, 1972 (AS17-148-22727). [NASA image record](https://images.nasa.gov/details/as17-148-22727) · [NASA image and media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). The image is public-domain NASA imagery; its use here does not imply NASA endorsement.

The [feature tour](../FEATURES.md) and [workflow guide](../GUIDE.md) show the windows in context. For build identity and test scope, see the [alpha release](https://github.com/kambuziarendal/listi/releases/tag/v0.38.0-23).
